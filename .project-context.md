## 2. Decisões Técnicas Críticas

### 2.1 AWS Profile Local
**`claude-dev`** — SEMPRE usar este perfil.

### 2.2 DynamoDB: Booleanos como Números
`e_popular` / `e_projeto` = `Number (0/1)` — DynamoDB não suporta Boolean como chave de GSI.

### 2.3 Next.js 16: `params` é Promise
`await params` ANTES de desestruturar em qualquer `page.tsx`.

### 2.4 Sharp.js: Build Especial para Lambda Linux
`backend/build.js` usa `npm install --os=linux --cpu=x64`. **NÃO alterar.**  
No Windows: `build.js` usa `PowerShell Compress-Archive` em vez de `zip`.

### 2.5 OpenNext v3: Caminho de Output
ZIP do Next.js: `frontend/.open-next/server-functions/default/` (**PLURAL**). `index.mjs` na raiz do ZIP.

### 2.6 NEXT_PUBLIC_API_URL: Runtime, Não Build

### 2.26 Pipeline de Imagens Responsiva — Mobile-First
- **imageProcessor Lambda**: gera 7 variantes por upload em paralelo (`Promise.all`):
  - `{basename}-480.avif`, `{basename}-480.webp` (mobile)
  - `{basename}-768.avif`, `{basename}-768.webp` (tablet)
  - `{basename}-1280.avif`, `{basename}-1280.webp` (desktop)
  - `{basename}-lqip.webp` (20px, quality 20 — LQIP blur placeholder)
  - AVIF quality 65 (effort 2), WebP quality 80

- **Formatos aceitos pelo admin**: PNG, JPEG, WebP, HEIC, HEIF.
- **`<ResponsiveImage>` component** (`frontend/components/ui/ResponsiveImage.tsx`): recebe `src` (basePath) e `lqip?` (data URI base64 inline). Renderiza `<picture>` com 6 variantes + blur placeholder via CSS `backgroundImage` quando `lqip` fornecido. Zero request HTTP para o placeholder.

### 2.66 FullwidthCallout — Componente Unificado (Sessão 25)
`frontend/components/ui/FullwidthCallout.tsx` + `FullwidthCallout.css` — substitui três implementações independentes:

**Props:**
- `variant?: 'light' | 'gradient' | 'newsletter' | 'dark' | 'navy'` — preset de cores via CSS `data-variant` + custom properties em cascata
- `border?: boolean` — borda accent topo/base (rgba(59,95,138,0.2))
- `size?: 'md' | 'lg'` — padding `var(--space-6)` ou `var(--space-7)`
- `icon?: string` — classe FA (ex: `'fa-envelope'`); omitir = sem ícone
- `iconVariant?: 'light' | 'dark'` — ícone accent-light bg vs accent bg
- `title: ReactNode`, `description?: string`
- `href?/ctaText?/ctaVariant?: 'accent' | 'white'` — botão opcional
- `rounded?: boolean` — `border-radius: 14px` para uso dentro de container (default false — fullwidth sem radius)
- `maxWidth?: string` — limita largura do conteúdo interno (ex: `"600px"`)

**Variantes:**
| variant | bg | título | descrição |
|---|---|---|---|
| `light` | accent-light | dark-900 | slate-500 |
| `gradient` | linear-gradient(150deg,#EBF1F8,#D0E4F2) | accent-dark | #475569 |
| `newsletter` | linear-gradient(135deg,#F8FAFC,#F1F5F9) | dark-900 | dark-700 |
| `dark` | var(--accent) Classic Blue | white | slate-300 |
| `navy` | var(--accent-dark) #1E3A57 | white | rgba(white,0.8) |

**Wrappers que mantêm API pública:**
- `SuperDestaque` → `variant="light" border icon="fa-envelope" iconVariant="light"`
- `PageCTA newsletter` → `variant="newsletter" size="lg"`
