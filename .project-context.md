### 2.67 Cache-Control immutable para arquivos public/ — Problema Conhecido (Sessão 23)
O `cd.yml` aplica `Cache-Control: public, max-age=31536000, immutable` para **todos** os assets Next.js via S3 sync. Isso é correto para `_next/static/chunks/*.js` (content-hashed) mas errado para arquivos de `public/` (ex: `foto-perfil-oculos.png`) cujo nome não muda entre versões.  
**Efeito:** browser que baixou versão antiga serve do cache por 1 ano, ignorando invalidações CloudFront.  
**Workaround imediato:** Ctrl+Shift+R (hard-refresh) ou incógnito.  
**Fix pendente (backlog #20):** separar o S3 sync em dois passos — `_next/static/**` com `immutable`, demais arquivos (public/) com `max-age=86400` sem `immutable`.

### 2.62 LQIP — Low Quality Image Placeholder (Sessão 19)
- **imageProcessor**: 7ª variante `{basename}-lqip.webp` (width: 20px, quality: 20) gerada em paralelo com as demais. Key: `media/${basename}-lqip.webp` (campo `keySuffix` no tipo da variante).
- **ResponsiveImage fill mode**: `background-image: url(${basePath}-lqip.webp)` + `background-size: cover` na `<picture>`. Browser upscaling de 20px → full size cria blur natural — sem CSS filter, sem JS.
