## 2. Decisões Técnicas Críticas

### 2.1 AWS CLI Profile Local
**`claude-dev`** — usar em TODA operação AWS local. Não usar `devops-blog-dev`.

### 2.2 DynamoDB: Booleanos como Números
`e_popular` e `e_projeto` são `Number (0/1)` — DynamoDB não suporta Boolean como chave de GSI.

### 2.3 Next.js: Params como Promise
`await params` ANTES de desestruturar em qualquer `page.tsx`. Já aplicado em todos os arquivos.

### 2.4 Sharp.js: Build Especial para Lambda Linux
`backend/build.js` usa `npm install --os=linux --cpu=x64` para sharp. **NÃO alterar.**

### 2.5 ZIP do Next.js — Confirmado
O ZIP deve conter os arquivos COM `index.mjs` na RAIZ do zip.  
OpenNext v3 output: `frontend/.open-next/server-functions/default/` (PLURAL, não singular).

### 2.6 NEXT_PUBLIC_API_URL: Runtime, Não Build
- Valor real: injetado via Lambda env var pelo Terraform em runtime
- No build CI: usa placeholder `https://build-placeholder.local`
- `lib/api.ts`: validação DENTRO de `getApiUrl()` (por request, não em module load)
- **NÃO** reverter para module-level throw

### 2.7 Admin: Build APÓS Terraform Apply
Admin Vue.js usa `VITE_*` vars baked no build. Pipeline builda admin APÓS `terraform apply` para usar os outputs reais (API URL, Cognito IDs).

### 2.8 Logging Estruturado
Todas as 8 Lambdas emitem JSON via `backend/src/common/logger.ts`.  
`LOG_LEVEL` controlado por variável Terraform: `DEBUG` (dev), `INFO` (prod).

### 2.9 Terraform Remote State
`providers.tf` configurado com backend S3. Precisa de bootstrap manual antes do primeiro `terraform init` com backend.  
Template: `infra/backend.hcl.example` → copiar para `infra/backend.hcl`.

### 2.10 ISR Pages com API — Fallback Obrigatório
Páginas com `export const revalidate = N` fazem fetch na API durante build. TODA chamada de API nessas páginas DEVE ter `.catch(() => fallback)`.  
Já corrigido: `app/page.tsx` (homepage).

### 2.11 PostSchedulerLambda — ConditionExpression
O UpdateItem usa `ConditionExpression: "#status = :programado"` para evitar double-publish em corrida (se dois schedulers rodarem simultaneamente).

### 2.12 CloudWatch Log Groups — Retenção Explícita
Todos os 8 log groups criados via Terraform com `depends_on` nas Lambdas.  
dev: 7 dias, prod: 30 dias (variável `log_retention_days`).
