## 2. Decisões Técnicas Críticas

### 2.1 AWS Profile Local
**`claude-dev`** — SEMPRE usar este perfil.

### 2.2 DynamoDB: Booleanos como Números
`e_popular` / `e_projeto` = `Number (0/1)` — DynamoDB não suporta Boolean como chave de GSI.

### 2.3 Next.js 16: `params` é Promise
`await params` ANTES de desestruturar em qualquer `page.tsx`.

### 2.4 Sharp.js: Build Especial para Lambda Linux
`backend/build.js` usa `npm install --os=linux --cpu=x64`. **NÃO alterar.**  
No Windows: `build.js` usa `PowerShell Compress-Archive` em vez de `zip`.

### 2.5 OpenNext v3: Caminho de Output
ZIP do Next.js: `frontend/.open-next/server-functions/default/` (**PLURAL**). `index.mjs` na raiz do ZIP.

### 2.6 NEXT_PUBLIC_API_URL: Runtime, Não Build
- Build CI: placeholder `https://build-placeholder.local`
- Validação dentro de `getApiUrl()`, não em module load

### 2.7 Admin: Build APÓS Terraform Apply
Vue.js bakes `VITE_*` vars — pipeline builda admin APÓS terraform apply outputs.

### 2.8 Logging Estruturado
JSON via `backend/src/common/logger.ts`. `LOG_LEVEL=DEBUG` (dev).

### 2.9 Terraform Remote State
S3: `marcelo-goncalves-blog-dev-tfstate/blog/terraform.tfstate`  
Lock: DynamoDB `marcelo-goncalves-blog-dev-tflock` | Profile: `claude-dev`

### 2.10 PostSchedulerLambda — Anti-Race
`ConditionExpression: "#status = :programado"` evita double-publish.

### 2.11 CloudWatch Log Groups — Ordem
`depends_on = [aws_cloudwatch_log_group.*]` garante retenção antes da Lambda existir.

### 2.12 CORS Admin — ADMIN_ORIGIN
`ADMIN_ORIGIN = "https://${module.admin.cloudfront_url}"` via Terraform. Fallback `*` dev local.

### 2.13 Lambda Function URL — OAC + AWS_IAM
`authorization_type = "AWS_IAM"` + OAC SigV4. Só CloudFront pode invocar. **Ativo** ✅

### 2.14 HTML Sanitization — sanitize-html
`backend/src/common/sanitizer.ts` em `savePost()`. Bundled pelo esbuild.

### 2.15 adminCategorias — admin-lambda-role
`categorias_table_arn` no `admin-lambda-policy`.

### 2.16 categoriesApi — Fallback Silencioso
Se API falhar, EditorView usa 6 categorias hardcoded.  
**Modelo real:** `{ categoria_slug, nome, descricao? }` — NÃO usar `nome_exibicao`, `icone_fa`.

### 2.17 FontAwesome — NPM, Não CDN
`import "@fortawesome/fontawesome-free/css/all.min.css"` em `layout.tsx`.

### 2.18 Testes Backend (Jest)
47 testes, 4 suites. Rodar: `cd backend && npm test`.

### 2.19 Pagination Limit Parametrizado
`?limit=N` em todos os endpoints. Defaults: recentes=6, artigos/categoria/busca=9, projeto=8.

### 2.20 GitHub Actions — OIDC
Role: `GITHUB-ROLE-FOR-MARCELO-TECH-BLOG`  
ARN: `arn:aws:iam::975707451904:role/GITHUB-ROLE-FOR-MARCELO-TECH-BLOG`  
Trust: `StringLike` → `repo:marcelo-jgoncalves/marcelo-goncalves-blog:*`  
(cobre `environment:dev`, `ref:refs/heads/*`, `ref:refs/tags/*`)

### 2.21 GitHub Actions — Node.js 20 Deprecation
`FORCE_JAVASCRIPT_ACTIONS_TO_NODE24=true` adicionado em `deploy.yml` e `cd.yml` (2026-04-27).  
Deadline GitHub: Jun 2026. actions/checkout@v4, setup-node@v4, upload-artifact@v4.
