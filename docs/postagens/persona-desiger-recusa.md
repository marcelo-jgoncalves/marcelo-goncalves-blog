Sobre as cores, achei excelente.
O contraste do fundo laranja (--aws-orange) com o texto azul escuro (--aws-dark) é clássico, de alta legibilidade e reforça muito a identidade da marca. O "Ler mais" em laranja também vai chamar muito mais atenção para o clique (CTA).

Sobre alinhar a tag (badge) à direita: Eu, como designer, não recomendo. ⚠️

Aqui está o porquê:

Padrão de Leitura em "F": No ocidente, lemos da esquerda para a direita, de cima para baixo. O olho do usuário busca naturalmente o canto superior esquerdo para começar a escanear o card. Se a tag estiver na direita, o canto esquerdo fica "vazio" e o título perde a âncora.

Equilíbrio Visual (Diagonal): O layout mais harmônico para cards costuma criar uma "diagonal de leitura":

Começa no Topo Esquerdo (Categoria/Tag)

Passa pelo meio (Título e Resumo)

Termina no Fundo Direito (Botão Ler Mais).
Se colocarmos ambos na direita, o card fica "pesado" de um lado só e o lado esquerdo fica parecendo que falta algo.

Conexão com o Título: A categoria funciona como um "subtítulo" ou contexto. Ela precisa estar visualmente próxima do início do título (que é alinhado à esquerda) para que o cérebro conecte os dois assuntos rapidamente.

Minha sugestão:
Vamos aplicar as cores que você pediu (que ficaram ótimas), manter o "Ler mais" na direita, mas manter a tag alinhada à esquerda. Isso cria o balanço perfeito.
