# Reports

Relatórios gerados pela auditoria de consistência do projeto (`/project-consistency-audit`).

Organizados por ano: `YYYY/<data>-<modo>-project-audit.md` (ex.: `2026/2026-08-04-full-project-audit.md`). Cada arquivo é uma execução datada, nunca reescrita depois de criada. Estrutura a partir de `../templates/audit-report-template.md`.

Estes relatórios são registros pontuais do estado do projeto na data da execução — não são estado operacional atual. Não editar um relatório existente para refletir mudanças posteriores; uma nova execução gera um novo arquivo. Fonte canônica das regras: `../project-consistency-audit.md`.
