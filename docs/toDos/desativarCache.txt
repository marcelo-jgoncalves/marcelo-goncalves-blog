Relatório Técnico: Configuração de "Debug Mode" (Cache Desativado)
Data: 08/02/2026 Contexto: O cache foi desativado em todas as camadas (CDN, Aplicação e Dados) para garantir que as alterações de código e conteúdo sejam refletidas instantaneamente durante o desenvolvimento.

1. Infraestrutura (CloudFront)
Arquivo: infra/modules/frontend/cloudfront.tf

O que foi feito: Alteramos o default_cache_behavior (rota padrão) para usar Managed Policies da AWS que impedem o armazenamento de cache.

Adicionado: cache_policy_id = Managed-CachingDisabled (ID: 4135ea2d...)

Adicionado: origin_request_policy_id = Managed-AllViewer (ID: 216adef6...)

Removido (Comentado): Bloco forwarded_values.

🔄 Como Reverter (Ativar Cache):

Remova as linhas cache_policy_id e origin_request_policy_id.

Descomente o bloco forwarded_values.

Descomente as configurações de TTL (min_ttl, default_ttl, max_ttl).

Execute: terraform apply -var-file="env/prod.tfvars".

2. Frontend - Dados (fetch)
Arquivo: frontend/lib/api.ts

O que foi feito: Nas funções de busca (ex: getPost), alteramos a estratégia de cache do fetch nativo.

Atual: cache: 'no-store' (Busca dados frescos no backend a cada requisição).

Anterior: next: { revalidate: 60 } (ISR - Cache por 60 segundos).

🔄 Como Reverter (Ativar Cache):

Troque cache: 'no-store' por next: { revalidate: 60 } (ou o tempo desejado).

Execute: npm run build e depois terraform apply.

3. Frontend - Roteamento Global
Arquivo: frontend/app/layout.tsx

O que foi feito: Forçamos o Next.js a renderizar todas as páginas dinamicamente no servidor (SSR), ignorando o Full Route Cache.

Adicionado: export const dynamic = 'force-dynamic'

Adicionado: export const revalidate = 0

🔄 Como Reverter (Ativar Cache):

Remova essas duas linhas constantes do topo do arquivo.

O Next.js voltará a usar o padrão (Static por padrão, Dynamic se usar headers/cookies).

Execute: npm run build e depois terraform apply.

⚠️ Resumo da Reversão (Checklist)
Quando formos para Produção, a ordem segura de execução será:

[ ] Código: Reverter api.ts e layout.tsx.

[ ] Build: Rodar npm run build no frontend.

[ ] Infra: Reverter cloudfront.tf.

[ ] Deploy: Rodar terraform apply.
